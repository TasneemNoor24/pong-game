# Pong Game

A simple Pong arcade game built with **Python** and **Pygame**.

## Features

* Player-controlled paddle
* Computer-controlled opponent paddle
* Ball movement and collision detection
* Score tracking
* First player to reach 5 points wins
* Simple arcade-style interface

## Controls

* **Left Arrow:** Move the player paddle left
* **Right Arrow:** Move the player paddle right
* **ESC:** Quit the game

## Technologies Used

* Python
* Pygame

## How to Run

1. Install Python.
2. Install Pygame:

```bash
pip install pygame
```

3. Run the game:

```bash
python pong.py
```

This project was created as part of my software development practice to demonstrate basic game programming concepts using Python and Pygame.
